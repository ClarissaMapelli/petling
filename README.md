# Petling 🐾

Projeto Integrador das disciplinas de Engenharia de Software III e Programação Back-End da Universidade Católica de Pelotas - UCPel.

## Sobre o projeto

O Petling é uma plataforma web voltada à divulgação de animais resgatados disponíveis para adoção e ao gerenciamento das solicitações de interesse em adoção.

## Funcionalidades previstas

- Catálogo de animais disponíveis para adoção;
- Pesquisa e filtros;
- Visualização dos detalhes dos animais;
- Registro de interesse em adoção;
- Área administrativa;
- Cadastro, edição e exclusão de animais;
- Gerenciamento das solicitações de adoção.
